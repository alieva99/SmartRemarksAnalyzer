# Проект: Разработка информационной системы для выявления повторяющихся замечаний заказчиков инжиниринговой компании на основе NLP

**Вариант:** ВКР (Выпускная квалификационная работа)

## Описание темы
Инженерная компания хочет создать систему, которая автоматизирует обработку замечаний от заказчиков. В строительных и инженерных проектах ежедневно приходят тысячи замечаний по документации. В настоящее время они обрабатываются вручную, что приводит к потере времени, невозможности выявить корневые причины ошибок и, как следствие, к повторению одних и тех же проблем из проекта в проект.

**Пользователи:** сотни инженеров-проектировщиков, десятки руководителей проектов (ГИПов), а также IT-администратор компании. Внешняя сторона — заказчики, которые направляют исходные замечания.

## Требования:
*   **Парсинг данных:** автоматическое извлечение неструктурированных текстов замечаний из реестров (содержащих текст замечания, автора, дату, тип замечания, проект, заказчика, статус).
*   **Обработка текста (NLP):** система должна автоматически очищать текст от шума, проводить лемматизацию и удалять стоп-слова.
*   **Классификация:** автоматическое определение типа замечания (оформление, коллизии, нормы и т.д.).
*   **Поиск дублей:** система должна находить семантически похожие замечания и группировать их в кластеры (с помощью машинного обучения).
*   **Визуализация:** предоставление руководителю интерактивного дашборда с информацией о повторяющихся замечаниях.
*   **Фильтрация:** возможность фильтровать замечания по проекту, заказчику, отделу и типу.
*   **Экспорт:** выгрузка аналитического отчета в Excel.
*   **Ручной ввод:** возможность добавления замечания вручную, если автоматический парсинг не сработал.

## Дополнительный контекст:
*   **Проблема перегрузки:** цифровизация строительства привела к росту объема данных, и менеджеры физически не успевают читать все замечания (информационная перегрузка).
*   **Бизнес-ценность:** внедрение системы позволит выявить "корневые причины" проблем и снизить количество повторных замечаний, экономя время и ресурсы компании.
*   **Ограничение MVP:** на первом этапе система обрабатывает только текстовые данные, замечания в виде сканов (картинок) игнорируются.
*   **Среда разработки:** система должна быть развернута локально на сервере компании, а интерфейс — работать через веб-браузер.
